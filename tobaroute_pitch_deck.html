01. LATAR BELAKANG & MASALAH

Tantangan Pariwisata & Ketimpangan UMKM Danau Toba

⚠️ Permasalahan Utama Wisatawan

  • Asimetri Informasi Rute: Wisatawan kesulitan menyusun itinerary efisien yang mencakup budaya, kuliner, dan keindahan alam Danau Toba.
  • Dominasi Destinasi Komersial: Destinasi utama sering overcrowded sementara destinasi budaya tersembunyi terabaikan.
  • Kurangnya Pembantu Cerdas Real-Time: Belum ada asisten AI lokal yang paham konteks budaya dan lokasi Geopark Kaldera Toba.

📊 Ketimpangan Ekonomi UMKM Lokal

  • Masalah "Popularity Bias": UMKM lokal hebat dengan ulasan < 15 review tenggelam dalam pencarian Google Maps/TripAdvisor.
  • Dampak Ekonomi Tidak Merata: Pengeluaran wisatawan terpusat di pusat kota Balige/Parapat tanpa menyasar perajin Ulos desa.
  • Kebutuhan Solusi Fairness: Diperlukan algoritma cerdas yang menjamin kesetaraan visibilitas bagi UMKM lokal berkualitas.
02. PENDEKATAN AI & MODELLING

Arsitektur RAG & Fairness Engine Algorithm

🧠 Hybrid RAG Pipeline

Mengintegrasikan Pinecone Vector Database dan Gemini Pro LLM dengan reranking Cohere Rerank v3 untuk akurasi rekomendasi lokasi 100% kontekstual tanpa halusinasi.

⚖️ Fairness Scoring Engine

Algoritma bobot dinamis:

Score = (0.5 * Rating) + (0.3 * DistanceScore) + (0.2 * FairnessBoost)

Memberikan dorongan visibilitas adil bagi UMKM lokal berulasan sedikit namun berkualitas tinggi.

🗺️ Interactive Route Optimizer

Integrasi Leaflet & Routing Machine untuk mengalkulasi rute titik-ke-titik paling hemat waktu dan bahan bakar melintasi spot wisata Danau Toba.

03. IMPLEMENTASI TEKNIS

Stack Sistem & Integrasi Superkomputer DGX B200

⚡ Tech Stack TobaRoute AI

  • Backend Framework: FastAPI (Python 3.11) + Async SQLAlchemy
  • Frontend Framework: React 19 + Vite + Tailwind/Custom CSS
  • Database: PostgreSQL (Relational) + Pinecone (Vector RAG)
  • Automation & Messaging: n8n Webhook + WhatsApp Reminder API

🖥️ Kontainerisasi DGX B200

Sistem TobaRoute AI telah dikontainerisasi secara utuh menggunakan Docker & Docker Compose:

  • Deployment 1-klik di cluster superkomputer DGX B200 IT Del.
  • Ketahanan penuh terhadap kendala jaringan dengan modul fallback offline.
  • Resource scaling otomatis di lingkungan server GPU.
